Scope

This diagram covers only how dm-crypt turns a sector number into the 16-byte IV that the cipher uses as its XTS tweak, for the default aes-xts-plain64. The tweak-encryption step and the rest of the key's kernel lifecycle are in key-lifecycle.html; the userspace path that leads up to luksOpen is in unlock-path.html.
